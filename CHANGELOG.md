# Changelog

## 0.1.1 (2026-10-01)
- Minecraft 26.3 support: the same version is published as two jars, `-neoforge-26.2` and `-neoforge-26.3`.
- 26.3: worldgen features, block states, loot tables, advancements and recipes converted to the new data formats.
- Mob spawns: fixed a crash on 26.3 biomes without a spawn list for the category.
- The jar now carries the license (`META-INF/LICENSE`) and the modification notice (`META-INF/NOTICE.md`).
- Bug reports point to this port's repository instead of the original project.

## 0.1.0 (2026-09-30)
- First NeoForge 26.2 build of the port (with Nicktale API instead of Citadel).
